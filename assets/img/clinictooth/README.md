# ClinicTooth screenshots

ClinicTooth is a **Capstone Project** — the card shows a "Capstone Project" badge.

Real ClinicTooth screenshots — wired into the project card automatically.

| File              | View                      |
| ----------------- | ------------------------- |
| `Front page.png`  | Front / landing page — **primary** (the only image visible on the card, and the first shot in the lightbox) |
| `1.jpeg`          | Dashboard                 |
| `2.jpeg`          | Patient portal            |
| `3.jpeg`          | Treatment records         |
| `4.png`           | Toothbot chatbot          |

Only `Front page.png` appears on the portfolio page; all screenshots open in the
click-to-explore lightbox (`View 5 screenshots` on the card). To swap an image,
replace the file with the same name — no code changes needed.
